# Pickle Benchmarks | 피클 벤치마크

유튜버 코드팩토리가 제안한 모델 비교용 메타프롬프트 다섯 과제를 **Pickle**이 수행한 결과를 모은 저장소입니다.
다섯 과제 모두 같은 원문 입력에서 출발했고, 각 결과물은 브라우저에서 바로 열리거나 실제로 빌드·검사한 파일입니다.
무엇을 검증했고 무엇을 하지 못했는지는 [WEB_VERIFICATION.md](WEB_VERIFICATION.md)에 그대로 적었습니다.

## 실행 방법

```bash
cd pickle-benchmarks
python3 -m http.server 8000 --bind 127.0.0.1
# 브라우저에서 http://127.0.0.1:8000/ 열기
```

`file://`로 직접 열어도 01·02·04·05는 동작하지만, 03은 ES 모듈·CDN 로딩 때문에 로컬 서버로 여는 편이 안전합니다.

### 01. 궁전 모션 그래픽 — `palace.html`

경복궁 근정전을 스터드 달린 브릭 모델로 코드로만 짓고(외부 3D 파일 0), 32초 동안 해부하는 모션.
모든 수치는 코드가 실제로 센 값이다.

| 항목 | 실측값 |
|---|---|
| 브릭 | **1,963개** — 월대 304 · 기둥 636 · 공포 308 · 지붕 475 · 마당 240 |
| 파트 | 5 (월대/기둥/공포/지붕/마당), 파트별 `InstancedMesh` 72개 |
| 단계 | 21 (브릭이 실제로 생성된 단계만 집계) |
| 바운딩 | 4,200 × 2,500 × 3,600 cm (몸체 3,000 × 2,100 = 정면 5칸·측면 5칸) |
| 에러 / 경고 | 겹침 0 / 결합부 경고 3 → 보강 브릭 6개 자동 배치 후 **0** |
| 생성 시간 | `performance.now()` 실측값을 화면에 그대로 표시(환경에 따라 300–1,200 ms) |

- **건축**: 2단 월대(84×68·72×54 셀, 계단 4단, 돌난간 110개), 주초·기둥 36본, 창호(한지+녹청/주홍 창살), 공포 5단,
  중층 팔작지붕(오목 처마 4단×2중, 추녀 솟음, 용마루·내림마루), 앞마당 박석 198 + 어도 + 품계석 2줄 16기,
  뒤로 인왕산 실루엣(브릭이 아닌 코드 배경이라 집계에서 제외).
- **연출**: 0–7s 바운딩 박스·치수 카운트업 → 층별 분해·재조립 / 7–13s 와이어프레임과 결합부 하이라이트(아래→위, 주황→파랑) /
  13–17s 모노톤, 지붕만 남기고 24% → 지시선 + 지붕 475 PCS / 17–23s 기둥 클로즈업, 경고 3→0 ✓ /
  23–29s 부품 인벤토리 5장 스태거 / 29–32s 하단 통계 6칸 카운트업. 32초가 0초와 같은 상태로 돌아와 이음새가 없다.
- **조작**: `setTime(t)` 공개(0–32 클램프, 결정론), 슬라이더·재생/일시정지·구간 점프 6버튼·키보드(Space/←→/1–6).

### 02. 한강시 게임 — `hangang-city.html`

서울을 닮은 가상 도시 '한강시'를 무대로 한 3인칭 오픈월드. 이름·로고·캐릭터·에셋은 전부 오리지널이고,
three.js 단일 HTML(외부 3D/이미지 에셋 0)에서 바로 실행된다.

- **도시**: 시드 RNG 1.4 km 격자. 한강(수면 셰이더), 사장교·아치교 2개, 업무지구 타워(45–150 m), 중층, 주거 골목, 상가, 공원.
  고가도로 1,120 m(교각 28·진입로 2), 주차빌딩 옥상 경사로, 한강타워, 오리지널 편의점 '한별24' 4곳, 한글 네온 간판 170개.
  건물 **764동**, AI 차량 28대, 보행자 54명.
- **물리**: 도보 4.4 / 달리기 8.4 m/s, 차량 최고 33 m/s, 전·후방 슬립 기반 드리프트, 원-AABB 충돌 반동,
  경사로·고가·옥상 지지 높이, 카메라 레이마치 충돌 회피.
- **시스템**: 비콘 E로 시작하는 미션 3종(시간제한 배달 / 26초 은신 따돌리기 / 고가·옥상 CP 5개 레이스),
  수배 1–3(과속·충돌 누적 → 순찰차 시야 추적, 이탈 시 감소), 신호등 위상(yellow 포함)을 지키는 AI,
  미니맵·디지털 속도계·수배 별·시계, 180초 낮→노을→밤 순환(야간 창문·가로등·네온 점등).
- **성능 설계**: 건물을 320 m 청크별 `InstancedMesh`(총 19개)로 묶고 240/440 m 거리 컬링 + 원거리 LOD,
  그림자 캐스터 거리 제한, FPS 44 미만 시 픽셀비 하향. **60 fps는 실측하지 못했다**(소프트웨어 렌더러).

**조작키와 구현 구조 5줄 요약**

1. **조작**: WASD 이동·운전, Shift 달리기/부스트, Space 점프/드리프트, F 탑승·하차, E 미션, 마우스 드래그·포인터락 시점(휠 줌), R 리스폰, H 도움말.
2. **도시**: 시드 RNG 격자 블록에 업무지구/중층/주거/상가/공원 성격을 배정하고 한강·교량 2개·고가도로·주차빌딩 옥상 경사로·편의점·한글 네온을 절차 배치.
3. **렌더**: 청크별 `InstancedMesh` + 커스텀 파사드 셰이더(창문 격자·야간 점등), 240 m 청크 거리 컬링과 원거리 LOD, 인스턴싱된 가로등/나무/보행자/차선, 태양광 그림자 추적, 적응 해상도.
4. **물리**: 원-AABB 충돌·반동과 경사로/옥상 지지 높이, 전·후방 슬립 기반 드리프트, 충돌을 피하는 3인칭 추적 카메라, 60 fps 목표.
5. **시스템**: 비콘 미션 3종(배달·따돌리기·고가/옥상 레이스), 수배 1–3과 순찰차 시야 추적·은신 감소, 신호 준수 AI 차량·보행자, 미니맵·속도계·180초 낮→노을→밤 순환.

> 검증 메모: 통합 단계의 재검증에서 인스턴스 색상 셰이더가 콘솔 컴파일 오류(`vColor` 미선언)를 남기는 것을 발견해,
> `enableInstanceColor()`에 4줄 셰이더 가드를 넣어 수정했습니다. 수정 후 헤드리스 Chromium 재검증에서 **콘솔 오류 0건**, 장면·HUD·상태값(건물 764동·간판 170·차량 61대) 동일을 확인했습니다.
> 발견 경위와 수정 내용은 [WEB_VERIFICATION.md](WEB_VERIFICATION.md) §3-2에 적었습니다.

### 03. 소개 페이지 — `model-intro.html`

'생각이 형태가 되는 순간'. 스크롤하면 **하나의 입자 구름**이 끊기는 섹션 없이 여섯 형태로 morph하며 이야기를 끌고 간다.
입자는 단일 `BufferGeometry`에 6벌의 목표 좌표를 담고, 커스텀 버텍스 셰이더가 이웃한 두 형태를 파티클별 시차로 보간한다.

| 구간 | 입자가 만드는 것 |
|---|---|
| 01 | **Pickle** 워드마크 — 오프스크린 캔버스에 이탤릭 세리프로 그린 글자의 픽셀을 샘플링, 커서 주변은 소용돌이·밀어내기 |
| 02 | 사고 트리 — 4단 재귀 분기, 뿌리→잎 한 경로만 액센트로 점등 |
| 03 | 코드 창 — 15행 코드 줄·줄번호 거터·액센트 캐럿, 실제로 눌러 실행되는 로컬 `pickle.run` 데모 |
| 04 | 긴 맥락 — 126장이 5.4π 나선으로 회전하며 반경 6.15→0.1로 한 점에 빨려 들어감 |
| 05 | 에이전트 — 6개 작업 노드(이중 링) → 3가닥 베지어 링크 → 액센트 결과 노드 |
| 06 | 입력창 — 실제 DOM 입력창 좌표를 측정해 그 둘레에 이중 궤도, Enter로 로컬 응답 |

- **디자인**: 따뜻한 오프화이트 `#F5F1EA` ↔ 깊은 먹색 `#141413`, 액센트 한 색 `#E2542C`, 세리프 헤드라인 + 모노 라벨, 한국어 카피 6개.
- **자리표시자**: 성능·벤치 수치는 지어내지 않고 `{{CONTEXT_WINDOW}}`, `{{BENCH_SCORE}}`, `{{TOKENS_PER_SEC}}`, `{{COST_PER_MTOK}}`로 남겼다.
  모델·제공사 이름은 파일 어디에도 없고 워드마크는 **Pickle**이다.
- **성능·접근성**: 파티클 상한 12,000(화면 폭·`hardwareConcurrency`·`deviceMemory`에 따라 8,000/5,400/4,200/2,200으로 감산),
  2드로콜, DPR 캡, 42 fps 미만 3회 시 픽셀비 하향, 탭 숨김 시 렌더 중단. `prefers-reduced-motion` 완전 대응,
  GSAP 미로딩 시 네이티브 스크롤 폴백, three.js CDN 1차 실패 시 2차 CDN, WebGL 없으면 안내 문구.

### 04. 단편 소설 — 「역상(逆像)」 · `novel.html` / `novel.md`

2031년 서울, 폐업을 앞둔 을지로의 활판 인쇄소. 70대 인쇄공 문 씨가 얼굴을 보인 적 없는 주문자의 원고를
매일 밤 한 문장씩 받아 조판한다. 그 문장들은 사십 년 전 그가 잃어버린 사람의 말투를 닮아 간다.

| 항목 | 실측값 |
|---|---|
| 본문 글자 수 | **12,386자** (공백 포함) / 9,183자 (공백 제외) |
| 원고지 환산 | **61.9매** (200자/매) — 요구 "60매 안팎" 충족 |
| 구성 | 장면 5, 본문 블록 133, 직접 대사 6 |
| 파일 | `novel.md` 30,356 B · `novel.html` 47,432 B |

- **요구 충족**: 3인칭 제한 시점, 활자 조판의 손 감각(활자 높이 23 mm, 납 냄새, 역상으로 읽는 글자, 먹·롤러·번짐),
  주문자 정체 미확정(번호·라디오·그림자·눈 속의 사람 4중 단서), 계절 늦가을→첫눈, 마지막은 인쇄된 한 장의 종이.
- **읽기 페이지**: 외부 요청 0. 종이색/먹색 테마(localStorage 기억), 글자 크기 7단계, 진행률 바, 장면 목차 패널,
  마지막 열네 문장은 종이 면 블록으로 별도 조판. 상세는 [NOVEL_README.md](NOVEL_README.md).

### 05. 촬영용 USB 컨트롤러 — TakeDeck TD-01 · `hardware/` / `1-controller-3d.html`

책상 위 작은 USB 촬영 컨트롤러 한 대를 요구사항부터 케이스 STL·회로도·펌웨어·PC 브리지까지 끝까지 만들었다.
REC 버튼은 OBS 녹화를 시작·중지하고, 빨간 LED는 버튼 표시가 아니라 **OBS의 실제 녹화 상태**를 반영하며,
0.96" OLED에 경과 시간·장면·연결 상태가 나온다. 통신이 끊기면 상태 불명을 명시한다.

| 항목 | 내용 |
|---|---|
| 크기 · 전원 | 96 × 74 × 24 mm (키캡 포함 약 37 mm) · USB-C 5 V, 실소비 약 45–60 mA |
| 구성 | Seeed XIAO RP2040 + SSD1306 0.96" I2C OLED + MX 스위치 4 + 5 mm 적색 LED |
| 제어 | OBS Studio 28+ 내장 obs-websocket v5, PC 쪽 Python 3.11+ 브리지(`host/`) |
| 납품물 | REQUIREMENTS·ARCHITECTURE·BOM(14품목)·WIRING·회로도 SVG·넷리스트, 펌웨어 소스+`.uf2` 프리빌드, 브리지+모의 OBS+pytest, 파라메트릭 CAD(`params.json`·`.scad`·STL 3종), Three.js 프리뷰 |
